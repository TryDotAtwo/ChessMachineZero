# Static position-artifact inspector

`numeric_trace.json` is the single browser data source. It is generated by
`python -m vm_compiler.site_trace` from the current 45-operation position
artifact and one Python/PyTorch reference fixture: `e2e4, d7d5, e4d5`.

The page decodes the visible board solely from exported `v45`; it does not
replay chess moves in JavaScript. The JSON includes complete zero-based COO,
source/artifact hashes, structured operation attributes, and bilingual
semantics for all 24 frozen tensors, 46 SSA values, and the two attention
intermediates. The browser rejects an inconsistent fixture or missing trace
metadata instead of displaying a plausible fallback, and recomputes generic
arithmetic to check the stored export. It does not launch `.cmz`/CUDA or
independently establish chess legality.

This is a static inspector, not native inference evidence. The artifact stores
packed E2M1/FP4 plus FP32 scales and current execution is FP32. Full QK and
hard-attention matrices are Python-reference debugging data; native production
uses an all-candidate scan with a selected-top-8 backward surrogate.

The current scope is position reconstruction from an already-valid history;
request rows, `LEGAL_SET`, status, and recurrent transition are not implemented
by this artifact. See dated `test_results/audit_corrections_2026-08-31.md` and
`test_results/task2_native_2026-08-31.md` for separately recorded evidence.

Serve locally:

```powershell
python -m http.server 4173 --directory site
```
