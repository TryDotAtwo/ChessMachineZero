    Реальная граница исполнения

    Артефакт восстанавливает позицию из уже валидной хронологической истории. Он игнорирует request-строки 0–2 и не реализует LEGAL_SET, проверку хода, terminal status или следующий recurrent context.

    Вес хранится как packed E2M1/FP4 + FP32 scales; текущая загрузка и вычисление — FP32. Полные QK и hard attention здесь — отладочный Python reference export, не захват всех native CUDA intermediates.

    Браузер проверяет арифметическую согласованность сохранённого экспорта; .cmz/CUDA здесь не запускается. Это не независимое доказательство шахматной легальности.

    Forward выбирает жёсткого победителя из всех 2064 кандидатов. Backward использует selected-top-8 softmax surrogate для Q/K/V; это не доказательство обучения или ускорения геометрического поиска.
